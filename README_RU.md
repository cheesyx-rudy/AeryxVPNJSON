# AeryxVPN JSON Subscription

Автоматически формируемая подписка AeryxVPN в формате JSON-массива Xray, совместимом с Happ.

[English](README.md) · **Русский**

## Подписка

- **JSON-подписка:** [AeryxVPN.json](https://raw.githubusercontent.com/cheesyx-rudy/AeryxVPNJSON/main/AeryxVPN.json)
- **Метаданные:** [AeryxVPN.metadata.json](https://raw.githubusercontent.com/cheesyx-rudy/AeryxVPNJSON/main/AeryxVPN.metadata.json)

Подписка предназначена для клиентов, поддерживающих Happ-совместимый формат JSON-массива Xray. Файл метаданных содержит сведения о формировании подписки, профилях, странах и заданном интервале обновления.

## Возможности

- Отдельные профили с группировкой узлов по странам.
- Общий профиль «Автовыбор», который выбирает узел по измеренной задержке.
- Балансировка на стороне клиента средствами Xray: `burstObservatory` и `leastPing`.
- Метаданные с временем генерации и текущей статистикой подписки.

Количество доступных узлов и стран меняется при каждом обновлении. Фактическая доступность и скорость зависят от сети, целевого сервиса и используемого клиента.

## Обработка и проверка

Автоматический процесс получает данные из настроенных источников, извлекает поддерживаемые прокси-конфигурации, применяет фильтрацию и устранение дубликатов, проверяет кандидатов с помощью приватного **AeryxVPN Core 1.0.0** и формирует JSON-подписку.

Перед публикацией сформированные профили дополнительно проверяются официальным бинарным файлом Xray-core.

Для публикации заданы пороговые условия безопасности. Если после проверки остаётся недостаточно подходящих конфигураций или не выполняются требования валидации, workflow сохраняет предыдущую опубликованную подписку, а не заменяет её неполным результатом.

Запуск автоматизации выполняется через подключённый внешний триггер `repository_dispatch`. Также предусмотрены ручной запуск в GitHub Actions и запуск при изменении `sources.enc`.

## Источники данных

Список источников хранится в этом репозитории в зашифрованном файле `sources.enc`. Во время выполнения workflow расшифровывает его с помощью секрета GitHub Actions. Ключ расшифровки и другие учётные данные нельзя добавлять в репозиторий.

Полноценный производственный процесс также зависит от отдельного приватного репозитория AeryxVPN Core и read-only токена GitHub Actions. Поэтому публичная копия этого репозитория сама по себе не является полностью автономной сборочной средой.

## Структура репозитория

| Путь | Назначение |
| --- | --- |
| `AeryxVPN.json` | Опубликованная JSON-подписка |
| `AeryxVPN.metadata.json` | Метаданные опубликованной подписки |
| `src/aeryx_json_parser/` | Код JSON-парсера и формирования подписки |
| `config/` | Настройки парсера и выходных данных |
| `schemas/` | JSON-схемы формируемых данных |
| `tools/` | Утилиты расшифровки источников и проверки |
| `.github/workflows/` | Автоматизация и CI |
| `LICENSE`, `LICENSE-SCOPE.md` | Лицензия на программный код и описание её области действия |
