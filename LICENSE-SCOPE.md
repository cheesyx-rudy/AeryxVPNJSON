The `LICENSE` file contains the unmodified PolyForm Strict License 1.0.0.

For this repository, the term **software** in that license refers only to original software code authored by the project licensor and located in these paths:

- `src/`
- Python source files (`.py`) directly inside `tools/`
- Python test source files (`.py`) directly inside `tests/`
- GitHub Actions workflow files inside `.github/workflows/`

Only the licensor's original portions of those files are covered. Third-party components and contributions are not covered by this license and remain subject to their own applicable terms.

## Materials not covered by PolyForm Strict

PolyForm Strict does **not** apply to configuration, subscription, or source-list data in this repository, including:

- `AeryxVPN.json` and `AeryxVPN.metadata.json`
- files in `config/`, including profile templates, routing data, and settings
- files in `schemas/`
- `sources.enc` and any decrypted source-list file, such as `sources.txt`
- data files such as `tools/core-versions.json`
- documentation and descriptive materials, including README, changelog, and research files
- precompiled or third-party tools, including `tools/mihomo`

Other files not expressly listed in the **software** section above are not covered by PolyForm Strict.

Configuration content originating from third parties remains subject to the rights and terms of its respective owners. This notice does not claim ownership of third-party configurations or grant rights that the project licensor does not hold.
